# Mandatory English-Only Rule

## Guidelines:
1. **100% English in UI:** All JetBrains UI dialogs, buttons, labels, hints, tooltips, and notification messages must be written exclusively in clear, professional English.
2. **100% English in Code:** All class names, function names, variables, log outputs, exception messages, and comments must be strictly in English.
3. **No Non-English Words:** Never use Uzbek, Russian, or any other non-English language inside plugin source code, resources, or CLI helpers.
4. **Target Audience:** The plugin is designed for global developers and distributed via the JetBrains Marketplace.
